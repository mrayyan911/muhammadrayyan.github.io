An always-on-top overlay that expands for details and remembers its position across displays. It supports simultaneous agents, approval indicators, and keyboard access from the system tray.

Imagenix

One workflow to upload, annotate, augment, and export image datasets. A full-stack platform connecting a web workspace to AI-powered image processing.

Next.js / NestJS / FastAPI / PyTorch

Read the Imagenix case study
Behind the build +

Grounding DINO handles auto-annotation, with Stable Diffusion and ControlNet for generative augmentation. Export formats include COCO, YOLO, and Pascal VOC.

The monorepo connects a Next.js frontend, NestJS API, and FastAPI ML service. PostgreSQL, Redis, BullMQ, and MinIO support data, jobs, and storage.
